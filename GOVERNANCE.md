# Governance

AMW is currently governed by a benevolent dictator for life model. Chris Sellers, GitHub user PetrefiedThunder, is the project founder and final maintainer for decisions about scope, releases, architecture, and contributions.

The project is pre-revenue and has a solo maintainer. Decisions will be made in public issues and pull requests whenever practical, with attention to technical merit, security, compatibility, and the open-core licensing split.

This model may evolve as the project gains regular contributors or adopts a formal maintainer group. Any change to governance will be documented in this file.
